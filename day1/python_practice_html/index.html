숫자 다섯 개에서 짝수를 찾으세요.

입력한 숫자를 리스트에 저장하고, 2로 나눈 나머지가 0인 값만 출력합니다.

리스트 · append() · for · 나머지 연산 %
다섯 개의 정수를 입력하세요.
Python 코드 보기
scores = []
for i in range(5):
    score = int(input(f"{i + 1}: 숫자를 입력하세요: "))
    scores.append(score)

print("입력한 숫자:", scores)
for number in scores:
    if number % 2 == 0:
        print(number)

반복문으로 구구단을 만드세요.

원래 실습의 작은 구구단과 전체 구구단을 표로 확인합니다.

중첩 for · range() · f-string
출력할 구구단을 선택하세요.
Python 코드 보기
# 작은 구구단
for dan in range(2, 5):
    for i in range(1, 5):
        print(f"{dan} X {i} = {dan * i}", end="\t")
    print()

# 전체 구구단
for multiplier in range(1, 10):
    for dan in range(2, 10):
        print(f"{dan} X {multiplier} = {dan * multiplier}", end="\t")
    print()

컴퓨터가 고른 숫자는 무엇일까요?

1~100 사이의 정수를 입력하세요. 크거나 작다는 힌트로 정답을 찾습니다.

random · while · if / elif / else · break
새 숫자를 골랐습니다. 첫 번째 도전을 시작하세요!
    Python 코드 보기
    import random

com_num = random.randint(1, 100)
count = 0
while True:
    user_num = int(input("1~100: "))
    if not 1 <= user_num <= 100:
        print("1~100 사이의 정수를 입력하세요.")
        continue
    count += 1
    if user_num > com_num:
        print("컴퓨터보다 큽니다.")
    elif user_num < com_num:
        print("컴퓨터보다 작습니다.")
    else:
        print(f"정답입니다! 총 시도 횟수: {count}")
        break
