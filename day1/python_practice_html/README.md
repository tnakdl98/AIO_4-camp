# 브라우저로 실행하는 기초 실습

`index.html`을 더블 클릭하거나 브라우저로 열면 바로 실행됩니다.
Python 설치, 서버 실행, 외부 패키지 설치, 인터넷 연결이 필요하지 않습니다.

상단 메뉴에서 실습을 선택하고 값을 입력한 뒤 실행 버튼을 누르세요.
숫자 맞추기는 정답을 맞힌 뒤 '새 게임'으로 다시 시작할 수 있습니다.
각 화면의 'Python 코드 보기'에서 원래 실습에 해당하는 예제를 확인할 수 있습니다.

## 구성

- HTML: 메뉴, 입력 폼, 결과 영역, Python 코드 예제
- CSS: 화면 배치와 모바일 대응
- JavaScript: 덧셈, 합격 판정, 짝수 찾기, 구구단, 숫자 맞추기

간단히 파일 하나를 열어 실행할 수 있도록 CSS와 JavaScript도 index.html 안에 넣었습니다.
이 페이지는 Python 파일을 직접 실행하지 않습니다. 동일한 실습 로직을 JavaScript로 구현했습니다.
Python 코드를 수정하며 연습하려면 기존 `python_practice_modules` 폴더를 사용하세요.

숫자 입력은 정수만 허용합니다. JavaScript의 정확한 정수 계산 범위는
±9,007,199,254,740,991이며, 범위를 넘는 입력과 덧셈 결과를 확인합니다.
점수 판정은 원래 Python 코드처럼 60 이상이면 합격이며 별도의 점수 범위 제한은 없습니다.
