# 블로그 작성 선호

이 작업 폴더에서 네이버 블로그 글을 작성하거나 다듬을 때 적용한다.

- 기준 글: https://blog.naver.com/psmsurim22/224448037271 (2026-10-20, 「5일차 | FastApi를 접하다」).
- 문체는 담백한 1인칭 서술형으로 쓴다. ‘~했다’, ‘~느꼈다’, ‘~인 것 같다’, ‘~해보고 싶다’처럼 배운 점과 생각을 자연스럽게 연결한다. 광고성 표현과 과장된 감탄을 피한다.
- 교안 요약을 나열하기보다 배운 개념, 이해에 도움이 된 방법, 어려운 점, 다음에 시도할 일을 연결하는 회고를 선호한다. 확인되지 않은 실습 경험이나 감정을 사실처럼 만들지 않는다.
- 주요 소제목은 `<소제목>` 형태로 쓰고, 네이버 편집기에서 나눔고딕, 19포인트, 굵게로 통일한다. 예: `<생성형 AI란?>`, `<Python 가상환경 — 프로젝트 전용 도구 상자>`, `<사용할 때 주의할 점>`, `<다음에 해볼 것>`.
- 코드와 실행 명령어는 네이버 편집기의 ‘소스코드’ 기능으로 입력한다. 일반 본문이나 마크다운 코드 펜스로 대체하지 않는다. CMD와 PowerShell 명령은 구분하고, 명령의 목적과 확인 방법은 주변 본문에서 설명한다.
- 기본 희망 분량은 공백 포함 2,000~3,500자이며, 해당 작업에서 다른 분량을 요청하면 따른다.
- 제목은 사용자가 직접 정하는 것을 우선한다.
- 사용자가 별도로 최종 발행을 승인하기 전에는 작성·수정 후 임시저장까지만 진행한다. 로그인 화면이 나오면 사용자에게 직접 로그인을 요청하며 비밀번호나 인증번호를 저장하지 않는다.

이 파일은 현재 작업 폴더에 적용되는 기록이다. 다른 폴더나 새 채팅에서 자동 적용된다고 보장하지 않는다.
